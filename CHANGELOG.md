## 0.3.0

- Add domain tabs generated from arbitrary registered domains and a separate
  Completed/Archived view.
- Show recorded research steps, purpose, and next work while preserving full
  technical details, uncertainty, and current-roadmap precedence.
- Add explicit project admission and opt-in discovery of hidden candidates;
  default sync does not scan the filesystem.
- Import dated project logs and route clearly attributable inbox activity into
  project history without creating TODOs or scientific acceptance.
- Support local terminal agents through the portable CLI and receipt contract.
- Upgrade existing public databases additively, retaining event identity and
  agent/session provenance.
- Preserve empty initialization, optional Slurm, arbitrary domains, portable
  runtime paths, agent-neutral operation, and the GET-only browser boundary.
